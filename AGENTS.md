# AGENTS.md

## KISS principle

Keep it simple. Prefer the most straightforward solution that works. Avoid unnecessary abstractions, premature optimization, and clever tricks. If there are two ways to do something, pick the simpler one.

## Git

Do not perform any write operations on git. Never commit, stage, merge, rebase, or push. Read-only commands (status, log, diff) are fine. The user handles all commits themselves.

## Generated code

`backend/packages/windiq_client/` is autogenerated from the WindIQ OpenAPI spec by `backend/scripts/generate-client.sh` and gets fully overwritten on regeneration. Never modify it by hand. All customization (auth, retries, timeouts) belongs in the handwritten facade under `backend/app/windiq/`, which is safe from regeneration.

`frontend/src/api/generated/` is autogenerated from the backend's own OpenAPI spec (`/api/openapi.json`) by `npm run generate:api` in `frontend/` (orval, config in `frontend/orval.config.ts`). Never modify it by hand — regenerate it (backend must be running) after changing the pydantic models in `backend/app/api.py`. Friendly type aliases live in `frontend/src/api.ts`; the fetch wrapper for the generated client in `frontend/src/api/fetcher.ts`.

## Comments

Do not add excessive comments. Code should speak for itself. Only add a comment to explain **why** something was done — never to explain **what** is being done.
