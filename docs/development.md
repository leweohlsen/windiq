# Development

## Full stack with hot reload

```sh
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

- Dashboard: http://localhost:5173 (Vite dev server)
- API docs: http://localhost:5173/api/docs (proxied to the backend)

The backend, worker and scheduler read WindIQ credentials from `backend/.env`. Copy
`backend/.env.example` and fill in `WIQ_CLIENT_ID` and `WIQ_CLIENT_SECRET`.

Source directories are bind-mounted. Backend changes reload through uvicorn `--reload`,
frontend changes through Vite HMR. After dependency changes, rebuild with `--build -V`:
the `/app/.venv` and `/app/node_modules` volumes are anonymous, and without `-V`
(`--renew-anon-volumes`) Docker keeps the stale ones and new packages never appear.
`Ctrl-C` stops everything. `docker compose down` also removes the containers and keeps the
`windiq-pgdata` volume.

The database is published on `127.0.0.1:5432` (user `windiq`, password from
`POSTGRES_PASSWORD`, default `windiq`), so local tools can connect directly.

## Running parts locally

Backend (Python 3.12+ and [uv](https://docs.astral.sh/uv/)):

```sh
cd backend
uv sync
uv run uvicorn app.main:app --reload
```

Frontend (Node 26, as in CI):

```sh
cd frontend
npm ci
npm run dev       # dev server
npm run build     # typecheck (tsc) + production build
```

## Tests

The backend tests need a running Postgres 17. `docker compose up -d db` provides one.
The suite creates and uses a separate `windiq_test` database.

```sh
cd backend
uv run pytest
```

Set `DATABASE_URL` if your database is not at the `.env.example` default
(`localhost:5432`, user `windiq`).

QC rules are tested with property-based tests (Hypothesis). Tests assert rules, not row
counts, because the API serves a sliding window. See
[api-measurements-quirks.md](api-measurements-quirks.md).

## Database migrations

Schema changes go through Alembic:

```sh
cd backend
uv run alembic revision --autogenerate -m "describe the change"
uv run alembic upgrade head
```

The `taskiq_messages` table belongs to taskiq-pg and is not part of the SQLAlchemy models.
`alembic/env.py` does not exclude it, so check autogenerated migrations and remove any
changes to that table.

## WindIQ API client

`backend/packages/windiq_client/` is generated from the WindIQ OpenAPI spec. Do not edit it
by hand. Regenerate it with:

```sh
cd backend
uv run scripts/generate-client.sh
```

Customization (auth, retries, timeouts) belongs in the handwritten facade in
`backend/app/windiq/`, which regeneration does not touch.

## API endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/health` | liveness, database status, last ingest run, data age |
| GET | `/api/metrics` | revenue chain (AEP gross/net, P50, P90), coverage, site parameters, data age |
| GET | `/api/daily?days=` | daily energy and mean wind, every window day present (max 365 days) |
| GET | `/api/wind?days=&resolution=` | per-bucket wind speed stats (mean/min/max) + interpolated-hours count/reasons/rejected originals and 16-sector wind rose over 30 days (max 365 days; resolution: hour/day/week) |
| GET | `/api/ingest/runs?limit=` | recent ingest runs (max 50) |
| POST | `/api/ingest/run?mode=sync\|backfill` | queue an ingest; returns `{queued: true}` immediately |

Full schemas: http://localhost:8080/api/docs (or `:5173` in dev).

## Project layout

```
backend/
  app/main.py          FastAPI app, /api/health, broker lifespan
  app/api.py           reading API and the ingest trigger
  app/worker.py        taskiq broker, schedule, startup sweep and backfill gate
  app/ingest/          backfill, sync, QC and the shared run logic
  app/db/              SQLAlchemy models, repository, engine
  app/windiq/          WindIQ client facade: auth, retries, timeouts
  packages/windiq_client/  generated OpenAPI client (do not edit)
  alembic/             migrations
  tests/               pytest, including Postgres integration tests
frontend/
  src/components/      dashboard panels (chart, wind, status, history, methodology)
  src/useDashboard.ts  polling hook (all panels, every 60 s)
  nginx.conf           gzip, asset caching, /api proxy, SPA fallback
docs/                  design documents (see the README)
```
